# Denges Auto Refresh

Build a complete, modern, premium website redesign for Garage de la Plaine in Denges, Switzerland.
IMPORTANT:
Use the existing Garage de la Plaine website as the source of truth for all factual information, services, contact details, opening hours, company information and existing pages:
https://www.garageplaine.ch/
Do not invent services, prices, company history, team members or other factual information that is not present on the existing website.
I am also providing a visual design reference/moodboard. Use this as the primary art direction for the new website. I want the finished site to feel extremely close to this visual language, while still being an original responsive website rather than simply recreating the image.
Overall design direction
Create a fresh, sophisticated Swiss automotive website that feels:
- premium but approachable
- trustworthy
- clean and modern
- local and established
- professional rather than flashy
- considerably more modern than a typical independent garage website
Avoid the stereotypical automotive look with excessive black backgrounds, racing graphics, carbon-fibre textures, aggressive gradients or too much red.
Use the visual reference as guidance:
- predominantly white / warm off-white background
- deep petrol/navy blue as the primary colour
- Suzuki red used sparingly as an accent
- pale sage/grey secondary backgrounds
- dark anthracite typography
- generous whitespace
- large editorial typography
- clean thin-line icons
- subtle borders and shadows
- refined rounded corners
- high-quality automotive and workshop photography
- restrained, smooth animations
The design should feel closer to a premium European automotive brand or contemporary Swiss company than to a traditional garage template.
Homepage
Create a strong homepage with the following structure:
1. Top information bar
Include the garage address and telephone number prominently but elegantly.
2. Navigation
Garage de la Plaine logo on the left and clear navigation for the main sections/pages from the existing website.
Include pages such as:
- Accueil
- Entreprise
- Véhicules
- Partenaire Suzuki
- Contact
Adapt these if the existing website contains additional important navigation.
3. Hero section
Large, highly visual hero section.
Main message:
“Votre garage de confiance à Denges.”
Supporting copy should communicate that Garage de la Plaine provides vehicle sales, maintenance and bodywork and has decades of local experience.
Include two clear CTAs:
- Voir les véhicules
- Prendre rendez-vous / Nous contacter
Feature a premium Suzuki vehicle within a Swiss/Vaud landscape or another high-quality automotive setting consistent with the moodboard.
Make the hero feel high-end, clean and spacious.
4. Trust / USP bar
Create four concise trust indicators inspired by the visual reference, such as:
- 40+ ans d’expérience
- Atelier multimarque
- Carrosserie toutes marques
- Pompe / service carburant if confirmed on the existing site
Use simple line icons.
5. Services
Present the garage's actual services from the current website in elegant cards.
Likely categories may include:
- Entretien & mécanique
- Carrosserie
- Pneus & géométrie
- Diagnostics & électrique
Verify these against the current website and use the existing information rather than inventing content.
Each service card should have a small icon, title, short description and link to learn more.
6. Véhicules en stock
Show a preview of approximately four available vehicles on the homepage.
IMPORTANT: Garage de la Plaine's current stock is supplied through Autolina.
The complete stock feed is:
https://www.autolina.ch/fr/iframe/30366?border=000000&buttons=f11c27&buttonsText=ffffff&footer=block&garantieFilter=none&icon=f11c27&links=000000&text=000000
Create a dedicated Véhicules en stock page where this Autolina inventory can be embedded or integrated.
Do not create a fake vehicle inventory database.
On the homepage, create a visually attractive vehicle-preview section leading to the complete stock page.
7. Suzuki partnership
Garage de la Plaine is an official Suzuki partner. Create a premium section explaining this partnership using factual information from the existing website.
Suzuki branding should complement the Garage de la Plaine brand rather than dominate the entire site.
8. Garage / company story
Create a section communicating the garage's history, experience and local roots.
Use the existing website for the factual copy.
Pair this with high-quality workshop/team imagery.
9. Customer trust
If real testimonials/reviews are available from the existing site or another supplied source, present them elegantly.
Do not invent testimonials.
10. Contact / appointment CTA
Create a strong final CTA encouraging visitors to contact the garage or request an appointment.
Include:
- telephone
- address
- opening hours
- contact form
- map/location
Use the factual information from the existing website.
Other pages
Rebuild all relevant information currently available on garageplaine.ch into a clearer modern structure.
The site should at minimum accommodate:
- Accueil
- Entreprise / À propos
- Services
- Véhicules en stock
- Suzuki
- Contact
If there are other important pages or content on the current site, preserve them appropriately.
UX requirements
Make the website fully responsive for desktop, tablet and mobile.
Prioritise easy actions for garage customers:
- call the garage
- find the address
- see available vehicles
- understand the services
- request an appointment
On mobile, make the phone/contact action particularly easy to access.
Use subtle premium animations: gentle image reveals, small hover interactions, smooth transitions and restrained scroll effects. Nothing gimmicky or excessive.
Typography and visual system
Follow the moodboard closely.
Use a strong modern sans-serif for headings, similar in character to Manrope, with a clean highly legible sans-serif such as Inter for body text.
Use a consistent design system across all pages:
- deep petrol/navy primary colour
- Suzuki red accent
- sage-grey secondary background
- warm off-white page background
- anthracite text
Buttons, cards, forms, icons and navigation should all feel like part of the same premium design system.
Important
Do not simply redesign the homepage and leave the rest generic. Build a coherent complete website.
Use:
Existing site = content and factual source
Attached moodboard = visual/design source
The objective is to make Garage de la Plaine look like a modern, trusted, high-quality Swiss garage while retaining all of the useful information and functionality they currently have.
